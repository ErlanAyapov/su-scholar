# Su Science
Название проекта: Разработка портала учета и анализа публикационной активности
Цель проекта:
Разработать информационный портал, который позволит централизованно вести данные о научных публикациях, быстро находить нужную информацию, отслеживать показатели публикационной активности и автоматически формировать отчеты по различным уровням структуры университета.

Основные задачи проекта:
    собрать данные по публикациям в одном месте;
    обеспечить поиск и фильтрацию;
    связать публикации с сотрудниками, кафедрами и институтами;
    считать показатели;
    формировать отчеты.
